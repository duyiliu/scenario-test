# 纯前端演示项目（画像：e2e）

单文件前端应用（`app.py` 同时托管页面与同源 API，端口 18082）：

- 登录表单（`demo / demo123`，Cookie 会话），错误提示 `#error`
- 登录后显示身份 `#identity`（"账号 demo"）与订单表格 `#order-table`（2 行）
- `#logout` 退出登录后回到访客态

预期场景（浏览器 E2E）：

1. 未登录显示"访客"，受保护接口返回 401
2. 错误凭据登录显示"账号或密码错误"
3. 登录成功显示"账号 demo"且订单表格渲染 2 行
4. 退出登录回到访客态

用于验证 skill 对纯前端项目走 `init --e2e` 托管链路，不生成 HTTP 场景模板。
